# Backlog — シンプルなタスク管理

スマホでの操作を前提にした、個人用のシンプルなタスク管理ツールです。
ビルド不要の静的サイト（HTML / CSS / JavaScript）で、GitHub Pages でそのまま公開できます。

## 機能

- タスクの追加（画面下部の入力欄）
- 状態は「未実施」「完了」の2種類。丸いチェックをタップで切り替え
- 未実施タスクは右端の `≡` をドラッグして並び替え → 上から順に優先順位（番号表示）
  - キーボードでは `≡` にフォーカスして ↑ / ↓ キー
- タスク名をタップで編集・削除
- 完了タスクは折りたたみ表示（新しく完了した順）。未実施に戻すと元の順位に戻ります
- メニュー（右上の `⋯`）から
  - 完了済みの一括削除
  - JSON でエクスポート / インポート（機種変更やバックアップ用）
- ホーム画面に追加してアプリのように使えます（オフライン対応）

## データの保存先

データはすべて **利用者のブラウザ内の localStorage** に保存され、サーバーには送信されません。
ブラウザのサイトデータを消去すると消えるため、必要に応じてエクスポートでバックアップしてください。

保存形式（キー `backlog.v1`）:

```json
{
  "version": 1,
  "tasks": [
    { "id": "…", "title": "…", "status": "todo", "createdAt": 1760000000000 },
    { "id": "…", "title": "…", "status": "done", "createdAt": 1760000000000, "completedAt": 1760000100000 }
  ]
}
```

`tasks` の配列順がそのまま優先順位です。状態は `app.js` の `STATUS` で定義しているので、
将来「進行中」などを増やす場合はここを起点に拡張できます。

## GitHub Pages で公開する

1. このリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. `main` ブランチに push すると `.github/workflows/pages.yml` が自動でデプロイします

## ローカルで動かす

Service Worker の都合上、`file://` ではなく簡易サーバー経由で開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000
```
